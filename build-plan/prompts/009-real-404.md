# 009: Real 404 (brief section 5 "Soft 404"; audit P3-6)

Read `build-plan/CONTEXT.md` first.

## Goal
Unknown URLs (e.g. `/does-not-exist`) return the home page with HTTP 200 because `public/.htaccess` rewrites every missing path to `/index.html`. The site has no client-side routes, so unknown paths should get a real 404 status and a branded page.

## Must haves
- `public/404.html`: static HTML using the shared header (the `data-site-header` / `data-nav-toggle` / `data-nav-menu` contract from 001), shared footer and `styles/page.css` tokens from 007 if present. Short message ("This page doesn't exist."), links to Home, Case study, JARVIS, KIN and the email. `<meta name="robots" content="noindex">`. Because it can be served at any depth, use ROOT-ABSOLUTE links and asset paths in this one file (`/`, `/work/evolve/`, `/styles/page.css`) and note why in an HTML comment.
- `public/.htaccess`: add `ErrorDocument 404 /404.html`. Remove the SPA catch-all rewrite (`RewriteRule . /index.html`) so missing files and directories fall through to the 404. Keep the existing cache headers. Keep `/`, `/work/evolve/`, `/jarvis/`, `/kin/`, `/assets/*` and all public files working. Add `404.html` to the no-store HTML rule (it already matches `\.html$`).
- Do not add security headers, redirects or anything else to `.htaccess` in this prompt; instead add a comment block `# TODO(Matt): HSTS / nosniff / Referrer-Policy / www->apex 301 (audit P3-7), add after review.`
- `public/sitemap.xml`: unchanged (404 is not listed). `stamp-assets.mjs`: make sure `404.html` gets the same asset stamping as the other static pages if it references stamped assets.

## Files
- `public/404.html` (new), `public/.htaccess`, `scripts/stamp-assets.mjs` (only if needed).

## Non-goals
- No server/host changes, no DNS, no other `.htaccess` behaviour changes.

## Verification
- `npm run build` passes and `dist/404.html` and `dist/.htaccess` exist.
- `node build-plan/verify/verify.mjs --checks <all previous>,404` passes (`404`: `dist/.htaccess` contains `ErrorDocument 404 /404.html` and no `RewriteRule . /index.html`; `/404.html` renders the shared header with a working menu at 390 and passes overflow/console checks).
